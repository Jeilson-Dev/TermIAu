# Claude Model — a TermIAu plugin

The session's model and effort level on each Claude panel's bar. Clicking either opens
the list to change it — `/model` (Fable, Opus, Sonnet, Haiku, the account default) or
`/effort` — typed into the panel's Claude; while it is working, the bar says to switch
once it stops.

Needs the Claude Code plugin, which the marketplace installs along with it.
