# Claude Context — a TermIAu plugin

How much of the context each Claude session has used, as a pill on its panel's bar:
the bar filling inside, the number on top. Yellow from one limit, red from another —
and in the red the whole panel gets a pulsing border. Clicking the pill, or `⌘⇧K`,
sends `/compact`; with **Compact on its own** on, it goes by itself when the context
reaches the limit and Claude is idle.

The limits are its settings, in **Preferences ▸ Plugins ▸ Claude Context**. Needs the
Claude Code plugin, which the marketplace installs along with it.
