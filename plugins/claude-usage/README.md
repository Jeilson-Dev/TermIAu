# Claude Usage — a TermIAu plugin

Claude Usage Monitor's circle in the footer's left corner: the circle is the time
left in the 5-hour session, and the number, how much of its usage still remains. The
color is the pace's — it lights up when you spend faster than time passes. With the
mouse over it, the session and the week open to the right, each with the time and the
usage left.

The numbers come from Claude Code's status line, through the Claude Code plugin,
which the marketplace installs along with it. The last reading is kept, so the footer
isn't empty until Claude speaks again.
